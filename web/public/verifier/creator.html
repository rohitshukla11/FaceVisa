How this is checked

Only receipts written by FaceVisa's published receipt address count, and each licence must be owned by the creator's own key and be for that exact file. A revocation record from the creator's key means "Revoked on <date>". Payments are checked on Whitechain: LicensePaid from FaceVisa's settlement contract, for that file, creator and price.

Only ads released through FaceVisa have receipts; a copy made elsewhere isn't on Arkiv. This page needs no FaceVisa server and works opened from disk.
